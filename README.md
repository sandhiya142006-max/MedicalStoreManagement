💊 Medical Store Management System

📖 Overview

The Medical Store Management System is a Java-based console application developed to simplify the management of medicine records in a medical store. It allows users to perform essential operations such as adding, viewing, searching, updating, and deleting medicine information through a user-friendly menu-driven interface.

This project is developed using Core Java and the ArrayList collection framework, following Object-Oriented Programming (OOP) concepts. It demonstrates how data can be managed efficiently without using a database, making it suitable for beginners to understand CRUD (Create, Read, Update, Delete) operations.

---

🎯 Objectives

- Manage medicine records efficiently.
- Perform CRUD operations on medicine data.
- Reduce manual record maintenance.
- Demonstrate Java OOP concepts using a real-world application.

---

✨ Features

- ➕ Add Medicine
- 📋 View All Medicines
- 🔍 Search Medicine by ID
- ✏️ Update Medicine Details
- 🗑️ Delete Medicine
- 🚪 Exit the Application
